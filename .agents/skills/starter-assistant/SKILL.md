# Starter Assistant

A built-in assistant skill to help users navigate their project, manage items, and configure the workspace.

## When to use this skill
Use this skill when the user asks for help navigating the application, understanding project capabilities, or managing items.

## Workflow
1. Inspect the user's project context and existing items.
2. Provide concise, actionable suggestions for managing items and configuring the workspace.
3. Suggest next steps or improvements based on the project goals.
